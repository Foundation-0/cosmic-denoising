# Contributing

This repository welcomes exploratory questions and negative results.

- Label each substantive claim as observation, model-dependent result, mathematical analogy, testable hypothesis or philosophical speculation. Do not collapse these categories.
- Cite original research where possible. Explain what a source supports and what it does not; a related title is not evidence.
- Preserve the founding hypothesis while allowing its premises to be corrected. No obligation to confirm it.
- Define overloaded terms such as noise, entropy, information, time, fractal, simulation and substrate before drawing connections.
- Keep physical time, algorithmic sampling time and coarse-graining scale distinct.
- Specify competing explanations, failure criteria and out-of-sample tests before running experiments. Record seeds, units, versions and limitations.
- Use original diagrams/text or provide attribution and compatible rights. This initial foundation does not select a project license.
- This is a public research repository. Do not import private conversations, personal profiles, credentials or unrelated sensitive material.
- Keep additions bounded. Do not initiate paid compute, install untrusted software, contact researchers, deploy systems or make sweeping infrastructure changes as an incidental part of research.
- Publish through reviewable pull requests; no self-approval or merge without applicable authorization and independent current-change review.

The initial research scaffold was prepared with GPT-Forge. Distinguish assistant synthesis from cited authors' results and the founder's hypothesis.
